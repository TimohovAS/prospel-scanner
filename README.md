# ProspEl receipt scanner

Android app that scans fiscal receipts into ProspEl.

This repository only hosts release builds. To install the app, open this link on the phone,
download the APK and allow installs from this source if Android asks:

https://github.com/TimohovAS/prospel-scanner/releases/latest/download/prospel-scanner.apk

ProspEl shows the same link as a QR code in **Settings → Receipt scanner connection**.
